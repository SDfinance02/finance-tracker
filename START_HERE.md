# Finance Tracker V2.4

V2.4 adds **Protection**: policies, annual premiums, renewals, coverage register and claims.

For an existing V2.3 source checkout, apply the V2.4 patch, test with `run_finance.command`, confirm **v2.4.0 / schema v5**, then use `publish_release.command` to publish the signed updater release.

After GitHub Actions is green, an installed V2.3 app can update from **Settings → Check for updates**.
