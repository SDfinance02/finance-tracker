# Finance Tracker V2.7

1. Apply `finance_tracker_v2_7_patch.zip` to your existing `finance_tracker_v2` project.
2. Run `run_finance.command`.
3. Open **My BV** and create your company, or switch to **Demo** to inspect the fictional BV first.
4. Confirm **Settings → v2.7.0 / schema 8**.
5. Create a local backup.
6. Stop development mode and run `publish_release.command`.
7. After GitHub Actions is green, open the installed older Finance Tracker app and install V2.7 through **Settings → Check for updates**.
