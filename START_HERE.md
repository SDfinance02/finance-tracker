# Finance Tracker V2.3

V2.3 introduces Household: Personal + Partner + Shared wealth in one consolidated dashboard while keeping the individual ledgers separate.

For the first V2.3 release, apply the supplied source patch, test with `run_finance.command`, then run `publish_release.command`. After the GitHub Actions release is green, test the real in-app update from your installed V2.2 Finance Tracker.

See `UPGRADE_TO_V2_3.md` and `V2_3_STATUS.md`.
