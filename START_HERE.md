# Finance Tracker V2.8

1. Apply `finance_tracker_v2_8_patch.zip` to your existing `finance_tracker_v2` project.
2. Run `run_finance.command`.
3. Open **Consolidated wealth**. Configure ownership and inclusion for each BV.
4. Switch between **Equity** and **Look-through** and inspect Demo if desired.
5. Confirm **Settings → v2.8.0 / schema 9**.
6. Refresh Household/Partner once so V2.8 can cache the new aggregate BV metadata.
7. Check a Household Future scenario and Decision Lab run if you use those modules.
8. Create a local backup.
9. Stop development mode and run `publish_release.command`.
10. After GitHub Actions is green, open the installed V2.7 app and install V2.8 through **Settings → Check for updates**.
