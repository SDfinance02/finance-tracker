# Finance Tracker V2.2 — start here

If you already have V2.1, use the **V2.2 patch**, not the full source ZIP.

After applying the patch:

1. Run `run_finance.command`.
2. Choose **Personal**.
3. Set your Finance Tracker password and optionally Touch ID.
4. Confirm your existing financial data is present.
5. In Settings confirm **v2.2.0 / schema v3 / database detected**.
6. Make one backup.
7. Run `build_app.command`.

V2.2 adds Personal / Partner / Demo profiles, native Touch ID, password fallback, separate ledgers and auto-lock. Your existing V2.1 database is preserved as Personal.
